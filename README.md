# Sweet Treats Bakery Website

## Overview
This project is a simple front-end bakery website built using HTML.

It focuses on clean layout design, color styling, and basic web structure to represent a bakery brand.

## Features
- Structured HTML layout
- Color-themed design for a bakery concept
- Clean and readable code
- Basic front-end development principles

## What I Learned
- How to structure a webpage using HTML
- How to apply color design and layout concepts
- The foundation of front-end web development

## Tech Used
- HTML

- Add CSS for advanced styling
- Make the site responsive for mobile devices
